Installing RetopoFlow from GitHub (Windows + MSYS2)

This guide builds the RetopoFlow add-on from source and prepares a GitHub-style release ZIP using the current repository scripts.

Prerequisites

  • MSYS2 Bash
  • Git
  • Blender installed on Windows
  • Internet access for cloning CGCookie repositories

Install script

#!/usr/bin/env bash
set -e

echo "=== Installing RetopoFlow build dependencies ==="
pacman -S --needed --noconfirm make rsync zip python

echo
echo "=== Creating projects directory ==="
mkdir -p ~/projects
cd ~/projects

echo
echo "=== Cloning/updating RetopoFlow ==="

if [ -d retopoflow/.git ]; then
  cd retopoflow
  git pull
  git submodule sync --recursive
  git submodule update --init --recursive
else
  git clone https://github.com/CGCookie/retopoflow.git
  cd retopoflow

  # Their addon_common submodule uses an SSH GitHub URL.
  # Change it locally to HTTPS so you don't need GitHub SSH keys.
  git config submodule.addon_common.url https://github.com/CGCookie/addon_common.git
  git submodule update --init --recursive
fi

echo
echo "=== Current RetopoFlow source ==="
git log -1 --oneline

echo
echo "=== RetopoFlow version ==="
python3 scripts/get_hive_value.py version || true

echo
echo "=== Looking for Blender ==="

BLENDER="$(find "/c/Program Files/Blender Foundation" \
-maxdepth 3 \
-type f \
-iname 'blender.exe' \
2>/dev/null \
| sort -V \
| tail -n 1)"

if [ -z "$BLENDER" ]; then
  echo
  echo "ERROR: Could not automatically find Blender."
  echo "Expected something like:"
  echo 'C:\Program Files\Blender Foundation\Blender 4.5\blender.exe'
  echo
  echo "Installed Blender directories:"
  ls -la "/c/Program Files/Blender Foundation" 2>/dev/null || true
  exit 1
fi

echo "Found Blender:"
echo "$BLENDER"

echo
echo "=== Blender version ==="
"$BLENDER" --version | head -n 2

echo
echo "=== Creating no-space Blender launcher for Makefile ==="

cat > /tmp/retopoflow-blender <

How to use

  1. Save the script as a .sh file in MSYS2 and run it from Bash.
  2. Wait for the repository to clone/update and build.
  3. Once complete, install the generated *GitHub.zip in Blender with Edit > Preferences > Add-ons > Install.

Notes

  • The script updates an existing local clone if present, otherwise it creates one in ~/projects/retopoflow.
  • This is designed for one-click-ish rebuilds while keeping submodules in sync.
