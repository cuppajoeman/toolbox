When repurposing an existing Steamworks app, changing the store page name is only one part of the rename. Steam keeps several separate names in different admin pages, and some of them need to be saved and published separately.

Places to rename

  1. Store page name: Go to the app landing page, then Edit Store Page > Basic Info, and update Game Name. Save the change. If the store page is already released, publish the store page changes too.
  2. Steamworks application name: Go to Edit Steamworks Settings > Application, and update the value under Application Name and Type. Save and publish the app data changes.
  3. Package names: On the app landing page, click the package listed near the top of the page. On the package page, use Edit Package Name. Check normal, beta, developer, and complimentary packages if the app has them.
  4. Depot names: Go to the Depots page in the app data admin. The depot name is editable, but the UI is a little hidden: click directly on the depot name and it should turn into an edit box. Rename it, save, then publish the app data changes.

Other things to check

  • Install folder names.
  • Depot names and build scripts.
  • Capsule art and library art.
  • Trailers, screenshots, and other media.
  • Any old name embedded in the game executable or launcher.

The Steam Community name may take longer to update than the admin pages. It can be normal for the community hub to show the old name for a couple of days after the Steamworks and store page values have been changed.
